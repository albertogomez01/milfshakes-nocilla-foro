# 🥤🍫 Foro Comunidad Milfshakes x Nocilla

Una aplicación web estilo foro moderna, rápida y estéticamente atractiva dedicada a la comunidad de entusiastas del reto **Milfshakes x Nocilla**.

## 🚀 Características

- **Diseño Visual Chocolate & Milkshake**: Paleta en tonos chocolate oscuro, avellana y acentos dorados con estilo *glassmorphism*.
- **Feed de Discusiones**: Hilos categorizados (Teorías y Pistas, Guías & Soluciones, General & Debate, Memes & FanArt).
- **Interacciones Completas**: Sistema de votos positivos/negativos, creación de nuevos hilos y comentarios en hilo.
- **Persistencia**: Todos los hilos, votos y respuestas se guardan automáticamente en `localStorage`.
- **Encuesta Comunitaria**: Componente interactivo de votación en tiempo real.
- **Vercel Ready**: Estructura optimizada para despliegue inmediato en Vercel.

---

## 🛠️ Cómo ejecutar localmente

1. Instala las dependencias:
   ```bash
   npm install
   ```

2. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Abre en tu navegador `http://localhost:3000`.

---

## ☁️ Cómo desplegar en Vercel

### Opción 1: Mediante la CLI de Vercel (Recomendado)
Ejecuta el siguiente comando en la terminal desde esta carpeta:
```bash
npx vercel
```
Sigue los pasos interactivos y en menos de 1 minuto tendrás la URL pública en Vercel.

### Opción 2: Desde GitHub
1. Sube este proyecto a un repositorio en GitHub.
2. Ve al panel de [Vercel](https://vercel.com) y haz clic en **"Add New Project"**.
3. Importa tu repositorio de GitHub. Vercel detectará automáticamente que es un proyecto **Vite** y lo desplegará instantáneamente.
